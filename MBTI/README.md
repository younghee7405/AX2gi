# 무역 MBTI (TradeType)

무역 도메인 성향 진단 테스트. 20개 질문에 답하면 4개 축(G/L, D/B, R/H, S/F)으로 성향을
진단하고, 무역 관련 직무 6가지 중 하나와 매칭해주는 Streamlit 웹앱입니다.

`trade_mbti_spec.md` 기획서를 기준으로 구현했습니다.

## 실행 방법

```bash
cd trade_mbti
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 표시되는 `http://localhost:8501` 주소로 접속하세요.

## 폴더 구조

```
trade_mbti/
├── app.py                # 메인 실행 파일, 화면 흐름(인트로 -> 질문 -> 결과) + 커스텀 스타일
├── .streamlit/
│   └── config.toml         # 테마 색상 (primaryColor 등)
├── data/
│   ├── questions.py       # 20문항 (축, 텍스트, 선택지 A/B, 부여 알파벳) + 축 메타데이터
│   └── jobs.py            # 6개 직무 정보 (설명, 하루 일과, 매칭 이유, 자격증, 궁합 등)
├── logic/
│   └── scoring.py          # 응답 집계 -> 4글자 유형 코드 계산 -> 트리 로직으로 직무 결정
├── requirements.txt
└── README.md
```

## 디자인 / 반응형

- `app.py`의 `inject_custom_css()`에서 커스텀 CSS를 주입해 질문·선택지 글자 크기를 키우고
  (선택지 1.2rem, 모바일에서도 최소 1.05rem), 질문/결과 화면을 카드형 UI로 정리했습니다.
- `.streamlit/config.toml`로 앱 전체 색상 테마(파란색 계열)를 지정했습니다. 사용자가
  Streamlit 설정 메뉴에서 다크모드로 바꿔도 카드/뱃지 배경은 `secondary-background-color`
  CSS 변수를 참조해 자동으로 맞춰집니다.
- Streamlit은 기본적으로 반응형입니다 — 화면이 좁아지면(`st.columns`로 나눈 버튼/카드 등이)
  자동으로 세로로 쌓입니다. 여기에 더해 480px 이하 화면을 위한 미디어 쿼리를 추가해서
  모바일에서 제목·버튼 글자 크기를 한 번 더 조정해뒀습니다.

## 채점 로직 요약

- 축별 5문항씩 총 20문항. 선택한 성향에 +1점씩 집계 (`logic/scoring.py`의
  `calculate_axis_scores`).
- 각 축에서 점수가 높은 쪽 알파벳이 최종 글자가 되며, 동점이면 기본값으로
  첫 번째 성향(G/D/R/S)을 채택합니다 (`determine_type_code`). 4글자 유형 코드는
  결과 화면에 그대로 노출됩니다 (예: `GBHF`).
- 실제 직무 매칭은 유형 코드가 아니라 기획서 4절의 if/else 트리로 결정됩니다
  (`match_job`): 축1(G/L)과 축3(R/H)으로 먼저 4그룹으로 나눈 뒤, 그룹에 따라
  축4 또는 축2로 세부 직무를 가릅니다.

## 결과 화면 구성

- 4글자 유형 코드 + 직무명, 한 줄 캐치프레이즈
- 직무 상세 설명 + 하루 일과 예시
- 이 성향이 왜 이 직무와 맞는지 이유 + 축별 점수 막대그래프
- 어울리는 활동/동아리, 관련 자격증 추천
- 궁합이 좋은 다른 직무 소개
- 다시 하기 버튼
- 결과 공유 버튼 — 현재는 텍스트 요약을 `.txt`로 저장하거나 복사하는 방식으로
  구현했습니다. 카드 형태의 PNG 이미지 공유는 기획서 8절의 "추후 확장 아이디어"로
  남겨두었습니다 (한글 폰트 임베딩이 필요해 별도 작업이 필요합니다).

## 커스터마이징

필요에 따라 자유롭게 수정하면 됩니다.
